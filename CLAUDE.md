# Claude Code implementation instructions

Read AGENTS.md, docs/architecture.md, and the relevant approved task before editing.

Implement only acceptance criteria in the issue or approved task. Prefer small PRs with tests. Do not edit review policy, workflows, or security controls as part of ordinary implementation tasks. Never access production credentials. If requirements conflict or architecture must change, stop and ask for a human decision.

In your PR, include: summary, tests run, limitations, and any architectural questions. Open a PR for review; do not merge.
